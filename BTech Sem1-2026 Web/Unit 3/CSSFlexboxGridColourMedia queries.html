Flexbox

Line things up, like friends sitting on a bench.

The big idea. Imagine friends on a bench. You decide if they sit in a row or in a stack, how much space is between them, and if they huddle on the left, on the right or in the middle. Flexbox lets you tell the browser all of that.

How to start

  1. Pick a parent box that holds the things you want to line up.
  2. Write display: flex; on the parent.
  3. The children inside are now flex items. Use the properties on the right to move them.
Mission: put every block in the exact middle of the box

Use justify-content: center and align-items: center together. One centres along the main line and the other centres across it.

display: flex

Turns the parent into a flex box. Its children line up in a row.

flex-direction

row puts items side by side. column puts them one under the other. Add -reverse to flip the order, so the last item comes first.

justify-content

Where items sit along the main line, the way they are lined up. space-between pushes the first and last items to the edges. space-around gives every item the same space on both sides. space-evenly makes every gap exactly equal.

align-items

Where items sit on the cross line, the other way. stretch makes them fill it. baseline lines up the bottoms of their first lines of text, like writing on a ruled line.

gap

The empty space between items.

flex-wrap

With wrap, items that do not fit start a new line instead of squeezing. wrap-reverse stacks the new lines the opposite way.

flex-grow

A greedy item! A number above 0 lets it grow to fill all the leftover space.

align-self

Written on one child. It lets that item ignore align-items and choose its own spot on the cross axis. Values: auto (do what the parent says), flex-start, center, flex-end, stretch, baseline.

Picture: the main axis and the cross axis

Every flex box has two invisible lines. The main axis is the direction the items line up in. The cross axis is the other direction, at a right angle to it. flex-direction decides which way the main axis points.

Solid pink line = main axis Dashed blue line = cross axis

Easy to remember: justify-content works along the main axis. align-items works across, on the cross axis. The main axis flips when you switch between row and column, so the two properties swap jobs. With row-reverse or column-reverse the main arrow points the other way, so start and end swap places.

Grid
Rows and columns, like a muffin tray or a chocolate bar.

    


    

        

            
The big idea. A muffin tray has rows and columns of little holes. A grid is the same. You say how many columns you want, and the items fill the holes one by one, left to right, then start the next row.

            
Flex or grid? Flexbox lines things up in one direction at a time. Grid handles rows and columns together. Use flex for a menu bar. Use grid for a whole page or a photo gallery.

            

                Mission: make 4 columns, a 20px gap, and block 1 two columns wide
                
Press 4 under columns, drag the gap slider to 20, and tick the box for block 1. Check that the code on the screen matches what you built.

            

        

        

            
display: grid
Turns the parent into a grid.

            
grid-template-columns
Says how many columns there are and how wide each one is.

            
fr
fr stands for fraction. It is a fraction of the available free space in the grid container. So 2fr gets twice as much space as 1fr.

            
repeat(3, 1fr)
A shortcut for 1fr 1fr 1fr. Three equal columns.

            
gap
The space between rows and columns.

            
grid-column: span 2
This item is greedy. It takes up two columns.

            
grid-template-areas
Draw your page with words, then give each part a name. See the page-layout toy below.

All the grid properties and their values

        
Grid properties come in two groups: the ones you write on the parent (the grid container) and the ones you write on a child (a grid item). Swipe the tables sideways on a small screen.


        
On the parent (grid container)

        

        

            
PropertyWhat it doesValues you can use

            
                
displayTurns the box into a grid.grid (a block-sized grid) inline-grid (a grid that sits inside a line of text)

                
grid-template-columnsSays how many columns there are and how wide each is.none 100px 10rem 25% 1fr auto min-content max-content minmax(100px, 1fr) fit-content(200px) repeat(3, 1fr) repeat(auto-fill, 100px) repeat(auto-fit, minmax(100px, 1fr)) [start] 1fr [end] (named lines) subgrid

                
grid-template-rowsSays how many rows there are and how tall each is.The same values as grid-template-columns.

                
grid-template-areasDraws the layout with names, one quoted line per row.none or quoted rows like "top top" "side main". A dot . means an empty cell.

                
grid-templateOne-line shorthand for rows, columns and areas.none 100px 1fr / 1fr 2fr (rows, then a slash, then columns) or areas with row heights.

                
grid-auto-columnsThe size of extra columns that the grid has to make by itself.auto 100px 1fr min-content max-content minmax(50px, 1fr)

                
grid-auto-rowsThe size of extra rows that the grid has to make by itself.The same values as grid-auto-columns.

                
grid-auto-flowWhich way new items fill the grid.row (the default) column dense row dense column dense

align-itemsMoves every item up or down inside its own cell.start end center stretch (the default) baseline

                
place-itemsShorthand: align-items then justify-items.center start end center stretch

align-contentMoves the whole grid up or down inside the box, when the rows are shorter than the box.start end center stretch space-between space-around space-evenly

Special words and functions

        

        

            
WordWhat it means

            
                
frA fraction of the available free space in the grid container.

                
autoSize to fit the content, and share out any space left over.

                
min-contentAs small as the content can get, like the longest single word.

                
max-contentAs wide as the content wants to be, with no line breaks.

                
minmax(min, max)At least min but never more than max.

                
repeat(count, size)Repeats the same size many times. repeat(3, 1fr) means 1fr 1fr 1fr.

                
auto-fillInside repeat(): makes as many columns as fit, even empty ones.

                
auto-fitLike auto-fill, but empty columns shrink away so the real items stretch out.

                
fit-content(size)As big as the content, but never bigger than size.

                
span nCross n columns or rows. span 2 means two.

                
subgridA grid inside a grid that reuses its parent’s rows or columns.

                
denseInside grid-auto-flow: fills holes by moving later, smaller items up.

Colour
Mix any colour you can imagine.

    


    

        

            
The big idea. Your screen is covered in tiny lights that glow red, green and blue. Mix different amounts and you get every colour. CSS gives you a few ways to write the same colour down. They all light up the same dots.

            
One tricky thing: CSS spells it the American way, color, without the “u”.

            
Where colours go

            
    
                
  • color paints the text.
    • 
                
  • background-color paints the inside of the box.
    • 
                
  • border-color paints the frame around the box.
    • 
            

            

                Mission: make a see-through orange for a background
                
Set the hue near 30, saturation near 100%, lightness near 50%, then drag see-through down to about 50%. Look at the checkerboard to see through it.

            

        

        

            
tomato
A name. There are about 140. Easy to remember, but you can only pick from the list.

            
#ff6347
A hex code. Two characters each for red, green and blue.

            
rgb(255, 99, 71)
How much red, green and blue, each from 0 (none) to 255 (full).

            
hsl(9, 100%, 64%)
Hue is the spot on the colour wheel (0 to 360). Saturation is how vivid. Lightness goes from black to white. This is the easiest one to play with.

            
hsl(9 100% 64% / 0.5)
The last number is alpha: 1 is solid, 0 is invisible, 0.5 is see-through.

Media queries
Pages that change shape to fit the screen.

    


    

        

            
The big idea. A phone, a tablet and a big computer have screens of different sizes. A media query asks the screen a question, like “are you narrower than 600 pixels?” If the answer is yes, the extra styles inside switch on.

            
It works like a rule at school: “If it is raining, wear a coat.” No rain, no coat.

            

                Mission: make the boxes stack in one column on phones
                
Put your grid or flex rule for one column inside @media (max-width: 600px) { ... }. Now it only happens on narrow screens.

            

        

        

            
@media
Starts the question. The styles inside the curly braces are the answer for “yes”.

            
(max-width: 600px)
“Is the screen at most 600px wide?” Great for phones.

            
(min-width: 600px)
“Is the screen at least 600px wide?” Great for bigger screens.

            
Last rule wins
If two rules both say yes, the one written lower down in your code wins.

            
(prefers-color-scheme: dark)
“Does this person like dark mode?” This very page asks that question!

            
(prefers-reduced-motion: reduce)
“Does this person want less movement?” Switch animations off to be kind.

            
<meta name="viewport" ...>
A line in your HTML <head> that tells phones to use their real width. Without it, phones pretend to be big and your query never fires.

        

    


    

        
Try it: what is asking the screen right now?

        
You are looking at this page on . Your window is 0 px wide.

        
Drag your browser window wider and narrower and watch the words change. On a phone, turn it sideways. This is a real media query, not a pretend one:


.device::after { content: "a computer"; }

@media (max-width: 900px) {
  .device::after { content: "a tablet"; }
}
@media (max-width: 600px) {
  .device::after { content: "a phone"; }
}
