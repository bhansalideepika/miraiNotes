# Project

## YouTube Clone with HTML & CSS

Basic representation of the YouTube homepage layout. The header section includes the YouTube logo, search input field, search button, and a user profile section. The main section includes a video thumbnail, title, description, and metadata such as views and posting date. You can repeat the structure within the main section to display multiple videos. The footer section contains a list of links and a copyright statement.

**Step 1: Set up the basic HTML structure.**

- Create a new HTML file and add the necessary HTML tags.
- Define the HTML structure using <header>, <nav>, <main>, <section>, and <footer> tags.
